## 핵심 결정

| 번호 | 결정 | 이유 |
|---|---|---|
| 주제 · 모드 | CAD 설계도대로 젠가 블록 가구를 쌓는 협동로봇. 자동 모드 + 협동 모드 | 10/3 사전 검증의 주제 판정 항목 5개(V-01 · V-02 · V-04 · V-11 · V-20)에 실패가 없었다 |
| D-01 | 1차(10/7) 완료 기준 = 자동(lv1_bench 11개, 3번 중 2번) + 협동 최소형(사람 2~3개 → 이어 쌓기 1번). 협동은 일정이 밀려도 뺄 수 없다 | 선행 프로젝트(8기 A-2 · HOME-CRAFT)와 다른 점이 협동 최소형에 있다([research](../research/README.md)) |
| A2 | MoveIt2를 필수 챌린지(핵심 기술)로. 모든 이동을 MoveIt2로 계획 · 실행 | 10/3 실기에서 사람 팔을 피해 갔고 끊김 · 떨림이 없었다. 10/4 실기 재검증에서도 동작 정상 |
| D-44 | 자주 가는 길은 정해 두고, **출발 전에** 막히면 다시 계획. 움직이는 중에는 멈추기만(1차) | 움직이는 중 새 경로로 갈아타기는 챌린지 ①로 나눠 1차를 줄였다 |
| D-11 · R-01 | 늘 켜 둔 정지 노드가 정지를 판단하고 제어기에 '지금 자리 서기' 궤적을 직접 보낸다. 잠금은 화면 '다시 시작'으로만 푼다 | 10/3 가상에서 MoveIt 취소 · `move_stop`으로는 팔이 안 섰다. 10/4 실기에서 Ctrl+C 즉시 정지를 확인([TS-01](../troubleshooting/TS-01_정지가_안_들음_R-01_v1_100415.md)) |
| A9-1 · D-32 | 사람이 멈추기 = 펜던트 · Ctrl+C · 화면 버튼 · 키 · 음성 '멈춰'(보조, PC 안 키워드). 출발은 화면 버튼 · 키로만 | 음성은 받아 적기 평균 1.8초, '정지' 5/10, 무음에서 말을 지어낸 일 2/10(V-18) |
| D-18 · D-17 | 1차 협동은 번갈아 하기. 사람 차례 끝 = 웹캠 · 손목 카메라 **둘 다** 손 없음 3초 + 칸 변화 + 출발 2초 전 알림. 웹캠도 1차부터 | 손목 카메라만 보면 가려졌을 때 잘못 넘길 수 있다(Gemini 지적) |
| D-21 · D-22 | 다음 블록 = 레시피 sequence에서 아직 안 놓인 첫 블록 + 비전으로 진행 확인. 잡기는 레시피 잡기 후보 그대로 | sequence대로 놓으면 양쪽이 막히는 칸이 생기지 않는다(7개 설계로 계산). 협동에서 생긴 막힌 칸은 사람에게 부탁 |
| A8 · D-26 | 블록마다 배치 확인. ±2 mm 안이면 그대로, 조금 더면 위층 보정, 기준 초과 · 무너짐이면 멈추고 사람 호출 | 7 mm는 구조 유지 한계(무너지는 경계)라 허용 오차로 쓸 수 없다. 로봇 배치 목표 ±2 mm와의 차이가 안전 여유다 |
| M-01 · D-14 | 공급 영역을 사람용 · 로봇용 둘로. 설계도 원점은 작업영역 가운데 한 점만 로봇으로 찍는다 | 사람과 로봇 동선이 겹치지 않게. 설계 파일은 그대로 두고 좌표 변환을 하나로 |
| D-34 | 챌린지 순서 ① MoveIt2 심화 → ② 흩어진 블록 → ③ 말 → 설계 만들기(VLA 대신) → ④ 남으면 | ①은 1차 협동과 바로 이어진다. ②는 로봇 시간이 많이 들어 휴일에. ③은 로봇 없이 개발할 수 있다. 학습형 VLA는 GPU · 로봇 시간이 부족하다 |
| D-03 | 역할 2 · 2 · 1 — 로봇 동작 박진용 · 한세교(+CAD), 비전 민범진 · 한석형, HMI 황인재(+PL) | 파트 안 일은 두 사람이 나누고 서로 백업. HMI는 황인재 혼자(10/4 PL 결정, 팀 규칙 ③ 예외) |
| 기술 | Docker · DB는 필수. 컨테이너 = DB + 서비스 PC 노드들, 로봇 PC는 호스트. DB 시기 · 제품은 HMI가 10/6 오전 화면 설계 뒤 결정(W051) | 평가 조건(컨테이너 + DB, PC 2대 이상 통신)을 1차 구조부터 맞춘다 |
| D-06 | 인터페이스 26개 — 이름은 `/d2/` 아래, 전용 메시지 `d2_interfaces`, 요청-결과는 전용 메시지 · 상태 방송은 JSON, CycloneDDS, 설정은 `config/robot.yaml` 하나, 판단은 한 곳에서 | 10/6에 다섯 명이 따로 개발하려면 약속이 먼저 있어야 한다. 정본은 [IRD](../02_인터페이스_IRD_v1_100415.md) |
