## 5. 인터페이스 (D-06, 26개 결정)

역할이 정해진 뒤 회의에서 모듈 사이 약속을 정했다. 전체 표 · 메시지 파일 · 칸은 [인터페이스 문서](../02_인터페이스_IRD_v1_100422.md)가 정본이다. 아래는 묶음별 요약이다.

| 묶음 | 정한 것 |
|---|---|
| 메시지 방식 | **섞기:** 요청-결과(집기 · 놓기, 진행 확인, 다음 블록, 그리퍼, 장면 붙이기, 화면 명령)는 전용 서비스 · 액션, 상태 방송(진행표 · 상태 · 사건 · 알림 · 사람 감지)은 JSON 문자열. JSON 맨 앞에 `"schema": "이름/1"`, 시각은 `stamp`(초) |
| 이름 · 패키지 | 모두 **`/d2/` 아래** + 파트 앞머리(`/d2/hmi` · `/d2/safety` · `/d2/vision` · `/d2/task` · `/d2/motion` · `/d2/gripper`). 전용 메시지는 **`d2_interfaces`** 하나(`PickPlace.action` · `GripperCommand` · `CheckProgress` · `NextBlock` · `HmiCommand` · `SceneAttach`) |
| 단위 · 번호 · 좌표 | 노드끼리 m · rad · 쿼터니언, 파일은 mm. JSON 칸 이름에 단위(`dx_m` · `force_n`). 블록 번호는 레시피 block_id(`LV1_B001`). 좌표는 `base_link`, 설계 좌표는 조립 원점으로 바꾼다 |
| 결과 · 실패 이유 | 서비스 · 액션 결과는 `success` + `reason`. 코드 8개: `PLAN_FAILED`(다시 계획 1번 → 호출) · `GRASP_FAILED`(1번 더 → 다음 칸 → 호출) · `SLOT_EMPTY`(다음 칸) · `OFFSET_OVER`(멈추고 호출) · `BLOCKED_BOTH_SIDES`(사람에게 부탁) · `HUMAN_IN_ZONE` · `VISION_LOST`(STOPPED) · `TIMEOUT`(호출) |
| 판단은 한 곳에서 | 멈출지 = **정지 노드** · 차례를 넘길지 = **작업 관리자** · 진행표 = **작업 판단**(주인) · MoveIt2 장면 = **장면 관리**(유일하게 고치는 노드). **→ S-02 · S-07:** 1차 장면 = 쌓인 블록 + 쥔 블록만(사람 팔은 챌린지 ①), `human_zone`은 1차에 정지 노드가 구독하지 않는다(W066부터) |
| 정지 경로 | 정지 노드가 서기 궤적을 **제어기에 직접**(`FollowJointTrajectory`, 지금 관절값 · 0.3초), 집기 · 놓기에는 `/d2/motion/halt`. 잠금은 화면 **'다시 시작'으로만** 푼다(`/d2/safety/resume`) |
| 화면 · 음성 | 출발(`start`)은 **화면에서만**(`/d2/hmi/command`). 음성은 뜻(`/d2/hmi/intent`)만 보낸다. **→ S-06:** `/d2/hmi/command`의 사람 차례 끝 값은 `turn_done`(옛 `human_done`) |
| 동작 묶음 | 집기 · 놓기는 **블록 1개 전체 액션**(`/d2/motion/pick_place`), 실행기는 같은 프로그램 안 클래스. 그리퍼는 **다 움직인 뒤 답**(`/d2/gripper/command`) |
| 설정 · 기록 | 설정은 **`config/robot.yaml` 하나**(보정 값만 따로). 기록은 **기록기 노드 하나**가 `/d2/task/event`를 받아 남긴다. **→ S-10으로 1차 범위 바뀜(D-35 기록):** 1차는 기록기 노드 없이 작업 관리자가 run_id CSV를 직접 쓴다. 기록 전용 토픽(`/d2/task/event` · `/d2/log/…`)과 기록기는 DB를 넣을 때(W051) 다시 본다 |
| 통신 · 실행 환경 | ROS 2 통신은 **CycloneDDS로 통일**, 모든 PC · 컨테이너 같은 `ROS_DOMAIN_ID`(번호는 다른 팀과 안 겹치게 정함). Docker 범위는 §4. 웹 연결(rosbridge / 웹 서버 직접)은 HMI가 정해 개발 |
| 개발 · 바꾸는 규칙 | 10/6 개발을 위해 **보내는 쪽이 가짜 노드(`mock_*`)**를 10/6 오전에 올린다(W034). 이름 · 칸을 바꾸는 PR은 **받는 파트 사람이 확인해야** merge, 커밋 `영향:`에 파트를 적고 `CHANGES.md`에 한 줄 |
