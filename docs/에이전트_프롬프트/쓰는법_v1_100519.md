# 팀원별 에이전트 프롬프트 — 쓰는 법

- 파일 하나가 한 사람 몫이다. **그 파일 하나만 붙여 넣어도** 에이전트가 프로젝트·역할·규칙을 알고 일할 수 있게 썼다.
- 넣는 방법(에이전트 종류에 맞게):
  - Claude Code: 작업 폴더(저장소)에 `CLAUDE.local.md`로 저장하거나 첫 메시지로 붙여 넣는다. 저장소의 `CLAUDE.md`는 팀 공통 읽기 규칙(`AGENTS.md`와 같은 내용)으로 쓴다.
  - Gemini CLI: `~/.gemini/GEMINI.md` 또는 작업 폴더의 `GEMINI.md`에 붙인다.
  - 그 밖(Codex 등): 첫 메시지로 붙이거나 `AGENTS.md` 아래에 덧붙인다.
- 단축 명령: `/start 이름`(처음 한 번 — 이 복사까지 대신 해 줌) · `/today 이름`(하루 시작) · `/wrap W번호`(작업 끝) · `/pr-review 번호`(승인자). 일정표는 `python3 tools/sched.py 이름`.
- 원본은 저장소 `docs/에이전트_프롬프트/`에 있다. 각자 자기 파일을 저장소 맨 위에 `CLAUDE.local.md`(Gemini는 `GEMINI.local.md`)로 **복사해서** 쓴다. 이 두 이름은 `.gitignore`에 있어 올라가지 않는다. 복사본에 덧붙인 개인 메모도 올라가지 않는다.
- 토픽·서비스 이름과 칸의 **정본은 `docs/02_인터페이스_IRD`**다. 프롬프트와 다르면 IRD를 따른다. 인터페이스나 일정이 크게 바뀌면 PL(문서담당)이 새 판을 올린다 — `git pull` 뒤 파일 이름의 월일시가 바뀌었으면 다시 복사한다.
- 파일 안 '참고 자료'는 모두 저장소에 있다: 문서는 `docs/`, 10/3 검증 코드는 `docs/research/ref_1003/`, 그림은 `docs/images/`. 지난 협동1 저장소는 https://github.com/hwang-injae/rokey_9_pjt1_D2 (공개).
