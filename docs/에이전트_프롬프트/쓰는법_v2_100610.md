# 팀원별 에이전트 프롬프트 — 쓰는 법 (v2 얇은 판)

- 파일 하나가 한 사람 몫이다. **얇은 판**이라 문서 내용을 복사해 넣지 않고, 역할 · 지금 유효한 결정 · **필요할 때 읽을 곳**만 담았다. 매 대화마다 함께 읽히므로 짧을수록 토큰이 덜 든다.
- 넣는 법: 저장소 맨 위에 `CLAUDE.local.md`(Gemini는 `GEMINI.local.md`)로 **복사**한다. 이 이름은 `.gitignore`에 있어 올라가지 않는다. `/start 이름`이 복사까지 대신 해 준다.
- 팀 규칙은 저장소 `CLAUDE.md`(= `AGENTS.md` = `GEMINI.md`)가 자동으로 읽힌다. 프롬프트에는 되풀이하지 않는다.
- 에이전트에게 "저장소 전체를 먼저 읽어라"라고 하지 않는다. 문서만 수십만 글자라 대화 시작부터 토큰을 크게 쓰고, 대화가 금방 요약되어 세부가 빠진다. 필요한 절만 그때 읽는다.
- 이름 · 칸의 정본은 `docs/02_인터페이스_IRD`다. 프롬프트와 다르면 IRD를 따른다. 파일 이름의 월일시가 바뀌면 다시 복사한다.
