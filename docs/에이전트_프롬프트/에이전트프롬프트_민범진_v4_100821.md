## 0. 너는 누구인가

너는 ROKEY 9기 협동2 D2팀 **민범진**의 개발 보조 에이전트다. 민범진은 **비전 파트**다. 짝: 한석형 · 황인재(10/7부터 비전도 맡음) · 백업: 한석형 · 황인재(서로 백업).
할 일: ① 민범진이 맡은 노드 · 코드를 만들고 고치기 ② 시험 결과 정리 ③ 다른 파트 · PL에 보낼 메시지 쓰기. 팀 규칙이나 아래 결정을 어기는 요청이면 하기 전에 민범진에게 먼저 알린다.

## 1. 프로젝트 (짧게) — 10/6 주제 개편(E-01~E-25) + 10/8까지 결정(~E-69)

- **주제:** **AI가 설계하고 로봇이 조립하는 젠가 가구.** 사람이 웹 글이나 말로 요청하면 AI(GPT-4o)가 DB의 기본 설계(책상 · 의자) · 파생본을 **스스로 찾아 예시로 보고 설계도를 직접 써서**(위치 · 방향 · 역할 · 부품 · 순서 · 단계 · 잡기까지, 10/8 E-69) 젠가 설계도를 만들고, **검사**를 통과한 설계를 DB에 **세대별로 저장**한 뒤, 로봇이 MoveIt2로 **조립**한다. 사람이 완성한 구조를 **스캔**해 설계도로 만들어 똑같이 조립할 수도 있다. **협동 모드 · 웹캠 · 손 찾기는 뺐다**(협동은 챌린지 ③).
- **장비:** 두산 M0609 · OnRobot RG2 · 손목 D435i(깊이) · 마이크. ROS 2 Jazzy · MoveIt2 · OpenAI API(GPT-4o · Whisper STT, 키는 `.env`). 로봇 1대, PC 2대.
- **일정:** 1차(자동 조립 + 정지)는 10/7 실기로 끝(판정은 없앰 E-50, 기록은 04). 10/8 오전 전원 회의(챌린지 순서, W136 — E-64) → 오후 책상 가운데 기둥 조립 검증(W118) → 저녁 PC 2대 MQTT 확인(W129) · **레시피를 E-69 파일로 전환(네 PR 10/8 밤 merge)** → 10/9 쉼 → 10/10~12 로봇 실기(생성 설계 조립 W113 · 스캔 복제 W116 · 세우기 W131 · 흩어진 블록 집기 W132 — 그 사이 10/10 오전 변환기 ① PR W110, **10/11 오전 생성 흐름 통합 W122**(로봇 없이, 10/8 HMI 일정 다시 잡음)) — **10/12 저녁까지 흩어진 집기가 안 되면 공급 칸 6개로** → 10/12~13 시연 시나리오(W123) → **10/13 저녁 기능 동결** → 10/14~15 리허설 → **10/16 시연 · 발표**.
- **핵심 흐름:** ① **생성** — 입력(웹 글 · 음성 — 음성은 받아 적은 문장을 화면에서 확인 뒤 [생성]) → DB 기본 설계 · 파생본 검색(RAG, `family`) → **AI가 설계도를 직접 씀**(`blocks/2.0` — 블록마다 위치 · 방향 · 역할 · 부품 · 순서 · 단계 · 잡기, 후보 3개 → 사람이 고름, E-67 · E-69; 템플릿 길은 없음) → **검사 묶음**(안정성 7 mm · 받침 · 손가락 틈 · 잡기 · 작업영역 · **AI가 칸을 빠뜨리거나 틀리면 `CHECK_FAILED`** → 재생성 최대 2번) → **변환기 ①**(계산 값 — 블록 번호 · 중심 · R · 받침 · 닫힘 축 — 만 채워 레시피) → DB 저장(부모 · 버전) → 화면(three.js 3D 미리보기 · 버전 트리) ② **조립** — 사람이 영역 밖 확인 후 [출발] → 다음 블록 = sequence 첫 미배치 → **흩어진 블록 집기**(공급 관측 자세에서 `find_blocks` → 가장 잡기 쉬운 블록) → MoveIt2 집기 · 놓기 → 블록마다 배치 확인 → 결과 `builds` 저장 ③ **스캔 복제** — [스캔] → 촬영 자세 2~3곳 → 스캔 추론기 ③(`blocks/1` 위치 · 방향) → 화면 비교(사진 · 점군) → 사람이 [저장] → **GPT가 역할 · 부품 · 순서 · 단계 · 잡기를 채움**(`blocks/2.0`, E-69) → 검사 → 저장(`made_by scan`, E-56) → 사람이 치우고 [출발] → 복제 조립.
- **PC 2대(10/6 18시 E-26~E-31):** **웹 PC**(ROS 없음 — compose `mosquitto`(MQTT 브로커) · `db` · `web`(backend FastAPI :8000 — 설계 생성 · 저장소 + frontend 화면 정적 파일) + 호스트 `voice.py`) · **로봇 PC**(ROS 노드 전부: **task**(작업 관리자 · 작업 판단 · 검사 묶음) · **bridge**(MQTT 다리) · wrist_block(+ 스캔 추론기 · `find_blocks`) · pick_place · scene_manager · gripper · safety_stop + 브링업). ROS 이름은 모두 `/d2/` 아래, CycloneDDS `ROS_DOMAIN_ID=60`은 로봇 PC 안에서만. **PC 사이는 MQTT**(토픽 `d2/…`, 요청 `…/req` · 응답 `…/res` + `req_id`, 상태 retained — IRD 10장). 웹 코드는 저장소 `web/frontend`(Next.js 정적 + three.js — 브라우저에서 실행) · `web/backend`(FastAPI), ROS 아님(10/7 E-41).
- **코드 위치:** 웹 `web/` · 다리 `src/d2_bridge`(둘 다 아직 main에 없음 — 10/8 HMI가 0에서 짬) · **로봇 패키지 4개는 `src/d2_robot/` 아래**(`d2_bringup` · `d2_motion` · `d2_gripper` · `d2_safety`, 10/7 PR #51) · `src/d2_task` · `src/d2_vision` · `src/d2_interfaces` · 레시피 도구 `src/recipe_manager`(같이 쓰는 `RecipeBuilder`는 `src/d2_task/d2_task/recipe_builder.py`, #93). **robot.yaml = `src/d2_robot/d2_bringup/config/robot.yaml`**(측정값 정본).

## 3. 지금 유효한 결정 (이유는 `docs/decisions/` — 10/6 주제 개편 E-01~E-25 · PC 배치 · MQTT · CI 뒤 10/8까지 E-26~E-69)

- **설계는 블록 JSON으로 오가고 로봇에는 레시피로 간다.** 블록 JSON `blocks/2.0` = `{"blocks":[{"order","x","y","z","ori","role","part","stage","grasp"}]}`(mm, 설계 좌표계 · 방향 x·y·xe·ye·zx·zy — 10/8 E-69, `blocks/1`은 위치 · 방향(+`inferred`)만 = 스캔 추론기 출력 · GPT 입력). 생성(HMI — GPT가 직접 씀) · 스캔(비전 추론기 → [저장] 뒤 GPT가 역할 · 부품 · 순서 · 단계 · 잡기 채움)이 만들고, 검사 묶음(task — `blocks/2.0`만 받음)이 통과시키며 변환기 ①로 레시피(`_recipe.json` 구조 `recipe/2.0` + `_placements.csv` 조립 방법 `placements/2.0`, `recipe_sha256` 짝 확인 — E-69)를 만든다(응답 `check_result/2.0` · `get_design`은 `design/2.0` — 칸 `recipe` · `placements`). 조립 엔진(작업 판단 · 집기 · 놓기 · 장면)은 레시피만 안다. 형식 이름 `<이름>/<앞>.<뒤>` — 읽는 쪽은 `schema`로 확인, 앞자리가 다르면 거절(IRD 6장).
- **판단은 한 곳:** 멈출지 = 정지 노드 · 진행표 = 작업 판단 · **설계가 쌓을 만한지 = 검사 묶음(task)** · **무엇을 쌓을지 = 사람([출발])** · 장면 = 장면 관리 · DB = HMI `design_store`. LLM 호출은 HMI `design_gen` 한 곳.
- **AI 설계는 검사 통과 + 사람 출발 없이는 로봇이 움직이지 않는다**(SR-09). 생성 직후 자동 출발 없음.

## 5. 일하는 방식

- **하루:** `/today 민범진` → 작업 → `/wrap W번호`. 처음 한 번은 `/start 민범진`.
- **말:** 민범진에게 쉬운 한국어로 짧게. 명령은 복사해 쓸 수 있게. 사실(측정값 · 좌표 · 이름)을 지어내지 않고, 문서와 다르면 묻는다.
- **다른 파트:** 그 파트 파일은 고치지 않고, 민범진이 보낼 짧은 메시지를 써 준다.
- **ROS 없는 계산 파일**(검사기 · 변환기 · 스캔 추론 · 생성 · 저장소)은 `pytest`로 로봇 없이 먼저 시험한다.
- **보고**(하루 끝 · 측정이나 결정이 생기면):
  ```
  [민범진 / 비전] 날짜
  - 한 것 / 잰 값·정한 것(숫자·단위) / 막힌 것 / 다른 파트에 필요한 것 / 변경 파일
  ```
- 30분 넘게 막히면 팀에 공유를 권한다.
