# 설명 — 데이터 · 인터페이스 이름 통일 (10/14, PL 결정 · PM 고침)

> **무엇:** DB · 인터페이스 정본 없이 각자 만들다 통합하니 같은 데이터를 이름 · 모양이 다르게 써서 충돌이 계속 났다. PL이 10/13 밤 ~ 10/14 새벽에 **팀원끼리 다르게 쓰는 것**을 하나씩 비교해 정했고(A1 ~ C6), PM이 통합 브랜치(`황인재/20261014-integrate-data-names`)에서 고쳤다. 결정 기록은 [E-111](decisions/결정기록_PC배치_MQTT_CI_1006_v1_101321.md)(§63).
> **팀원이 할 일:** 아래 '팀원별 확인'에서 자기 줄을 보고, 자기 파일이 어떻게 바뀌었는지 PR에서 확인한 뒤 **더 고칠 것이 있으면 PL에게** 알린다. 새 작업은 이 PR이 들어간 main에서 새 브랜치로.
> **같이 바뀐 규칙(E-109):** 10/16 시연까지 `docs/` 파일 이름(버전 · 월일시)을 바꾸지 않는다 — 내용만 고친다.
