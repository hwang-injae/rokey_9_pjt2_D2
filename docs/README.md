## 문서 파일 이름 규칙 (팀 규칙 ⑨)

```
이름_v<버전>_<MMDDHH>.md
예: 03_설계_SDD_v1_100422.md   (v1, 10월 4일 14시)
```

- **버전은 크게 바뀔 때만** 올린다(v1 → v2). 작은 수정은 버전을 그대로 두고 월일시만 새로 쓴다.
- **이전 판은 git 이력**에 있다. 저장소·드라이브에 옛 판 파일을 두지 않는다 — 새 판이 나오면 옛 판은 지운다(10/4 PL 결정).
- 이름은 손으로 바꾸지 않고 도구로 바꾼다. 저장소 맨 위 `README.md`와 `docs/` 안의 링크도 새 이름으로 같이 고쳐진다. `snap`은 쓰지 않는다.

  ```bash
  python3 tools/docver.py touch <파일>   # 작은 수정: 버전 그대로, 월일시만 지금으로
  python3 tools/docver.py major <파일>   # 큰 변경: v1 -> v2
  python3 tools/docver.py touch <파일> --dry-run   # 바꾸지 않고 결과만 보기
  ```

- 이 규칙에서 빼는 것: 폴더 안내 `README.md`, `.github/` 파일, 코드.
- 시험 기록(`test-reports/`)은 `<ID>_<내용>_<이름>_v1_<MMDDHH>.md`, 트러블슈팅은 `TS-번호_짧은제목_v1_<MMDDHH>.md`로 쓴다.
