# 05 작업 분류 — 파트별 할 일 (10/4 확정 배정)

- 대상: 팀원 5명. 파트 2명이 이 문서를 보고 파트 안 일을 나눈다.
- 날짜는 일정표(드라이브, v5)의 Time Line·이름 시트와 같다. 일정표 작업에는 번호 `[W001]`~`[W100]`이 있다(표의 날짜 칸 끝에 적음. 합쳐지거나 없어진 번호는 비어 있다). 작업을 끝내면 PR 본문에 `완료: W번호`를 적는다 → PL의 문서담당 에이전트가 일정표에 반영한다.
- 시나리오는 [설계 문서](03_설계_SDD_v1_100416.md), 결정 근거는 [결정 기록](decisions/결정기록_시나리오_역할_인터페이스_1004_v1_100416.md)에 있다.
- 표 읽는 법: **완료 기준**을 채우면 그 작업은 끝이다. **먼저 필요**는 시작하기 전에 끝나 있어야 하는 것이고, **넘겨줄 곳**은 결과를 쓰는 파트·묶음이다.
- 큰 흐름(10/4 PL 결정, 15시 간소화 반영): 10/6 낮에 모듈을 빠르게 만들고(가짜 노드로 혼자 확인만) → 10/6 저녁 **기능별 통합 확인 ①·②**(가상, 2개) → 10/7 **전체 통합 ① 자동 · ② 협동**(실기) → 10/7 저녁 1차 판정. 자세한 순서는 5장. 10/4 15시에 1차 범위를 줄인 내용(S-01~S-13)은 9장.
