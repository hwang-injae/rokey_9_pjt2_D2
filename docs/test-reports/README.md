# 시험 기록 (test-reports) — 색인

> 실기 · 가상 시험 기록 중 **설계 · 결과의 근거가 되는 것**을 모은다. 요약 수치는 [결과표](../04_결과_결과표_v1_100519.md)에 있다. 영상 · 코드 · 압축 파일은 저장소에 넣지 않는다(팀 노션 결과 페이지).
>
> 파일 이름: `<ID>_<내용>_<이름>_v1_<MMDDHH>.md` (예: `V-01-04_블록쌓기실험_황인재_한세교_v1_100314.md`). ID는 검증 항목 번호(V-xx) 또는 위험 · 할 일 번호(R-xx). 고칠 때는 [docs 안내](../README.md)의 문서 파일 이름 규칙대로 `tools/docver.py`를 쓴다.
>
> 검증 수준: **실기** = 실제 로봇 · **가상** = 두산 에뮬레이터 + RViz · **자동** = 로봇 없이 도는 자동 시험(pytest 등) · **손** = 로봇 없이 사람이 직접 쌓은 실험.
