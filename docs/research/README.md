# 조사 자료 (research)

주제 선정("왜 이 주제인가 · 무엇이 다른가")에 쓴 조사와 참고 자료다. 10/3 주제 확정 무렵 조사한 내용이라, 최종 구현은 [설계 문서](../03_설계_SDD_v3_100719.md)와 [결과표](../04_결과_결과표_v2_100719.md)를 따른다.

## 1. 선행 프로젝트와 차별점

> **10/6 주제 개편으로 차별점이 바뀌었다(E-01 · E-03).** 지금 차별점: 설계도를 **AI가 만들고 검사하고 세대로 관리**하며, 로봇은 그 설계도를 그대로 쌓는다. 실물을 스캔해 설계도로 복원 · 복제한다([저장소 README](../../README.md)). 아래 한 줄 · 표의 '우리가 다른 점'은 10/3 기준이다 — 같이 쌓기(협동)는 챌린지 ③, 양쪽 막힌 칸 부탁은 뺐고(E-13), 말 → 설계는 핵심이 됐다(E-08).

10/3 설계 점검 때 공개 README로 확인했다. 'CAD대로 혼자 쌓기'와 '손을 MoveIt2 장애물로 넣기'만으로는 새롭지 않다는 것을 알고, 차별점을 아래 한 줄로 고정했다.

> **사람이 설계도의 빈 자리에 아무 순서로 블록을 놓아도, 로봇이 진행 상태를 읽고 다음 블록을 골라 이어 쌓는다.**
> 그래서 협동 최소형(사람 2~3개 → 로봇이 이어 쌓기 1번)은 일정이 밀려도 1차 완료 기준에서 빼지 않는다(D-01). **(→ 10/6 E-03 · E-23: 협동 최소형은 1차에서 뺌)**

| 프로젝트 | 한 것 | 우리와 겹치는 점 | 우리가 다른 점 |
|---|---|---|---|
| ROKEY 8기 A-2조 | 젠가 검사를 하면서 YOLO로 찾은 작업자 손을 MoveIt 충돌 물체로 넣어 피했다 | 사람 손을 MoveIt2 장애물로 | 피하기에서 끝나지 않고, 사람이 **같은 가구를 같이 쌓는다**. 사람이 놓은 블록을 손목 카메라로 읽어 진행표에 반영하고 이어 쌓는다 |
| HOME-CRAFT | 웹 3D CAD로 설계하면 M0609가 LEGO를 자동 조립한다. 이미 놓인 블록은 빼고, 낮은 층부터 이웃 상태를 보고 조립 방법을 고른다 | CAD 설계 → 로봇이 혼자 조립 | 맞물림이 없는 **젠가 블록**이라 놓는 정밀도(배치 목표 ±2 mm)와 블록마다 배치 확인이 중요하다. 사람이 **순서와 상관없이** 끼어들어도 로봇이 이어 간다. 양쪽이 막혀 손가락이 못 들어가는 칸은 사람에게 부탁한다 |
| CMU BrickGPT (연구 · ICCV 2025 최우수 논문) | 글로 설명한 구조물을 무너지지 않게 설계해 로봇이 조립한다. 서로 맞물리는 블록과 양팔 로봇을 썼다 | 말 → 설계 → 조립 | 우리는 책상 크기 · 팔 하나 · 맞물림 없는 블록 · 사람이 옆에서 함께. 말 → 설계 만들기는 챌린지 ③(LLM이 레시피를 쓰고 형식 · 안정성 검사를 통과하면 쌓기)으로만 한다. 학습형 VLA는 하지 않는다 |

- 산업 쪽에도 설계 데이터대로 재료를 쌓고 조립하는 로봇(벽돌 쌓기 로봇 · 목조 부재 조립 로봇)이 있다. 우리는 이것을 책상 크기로 줄이고 사람과의 협업을 더했다.
- 발표에서는 선행과 겹치는 부분(손 회피 · CAD 조립)을 숨기지 않고, 위 차별점을 시연(협동 모드로 몇 블록)으로 보여 준다. **(→ 10/6 E-03: 협동 모드는 챌린지 ③으로 바뀜)**
