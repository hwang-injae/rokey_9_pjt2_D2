# 05 작업 분류 — 파트별 할 일 (10/6 주제 개편 반영)

- 대상: 팀원 5명. 파트 사람들이 이 문서를 보고 파트 안 일을 나눈다(황인재는 10/7부터 비전 · HMI 두 파트, E-42).
- 날짜는 일정표(드라이브, **v10**)의 Time Line · 이름 시트와 같다. 작업 번호 `[W001]`~. **10/6 개편으로 새로 생긴 작업은 W108~W125**(그 뒤 W126~W134), 뺀 작업은 8장. 작업을 끝내면 PR 본문(황인재는 커밋 메시지)에 `완료: W번호`를 적는다 → 문서담당 에이전트가 일정표에 반영한다.
- 주제 · 범위는 [요구사항 v3](01_요구사항_BR-SR_v3_100710.md), 결정 근거는 [결정 기록 10/6](decisions/결정기록_주제개편_1006_v1_100616.md), 이름 · 칸은 [IRD v3](02_인터페이스_IRD_v3_100710.md), 흐름은 [설계 v3](03_설계_SDD_v3_100709.md).
- 표 읽는 법: **완료 기준**을 채우면 끝. **먼저 필요**는 시작 전에 끝나 있어야 하는 것, **넘겨줄 곳**은 결과를 쓰는 곳.
- 큰 흐름: 10/6 저녁 기능별 통합 확인(가상) → **10/7 1차 판정 = 자동 조립(벤치) + 정지**(E-23). 같은 날부터 **핵심**(AI 생성 · 검사 · 변환 · DB · 화면)은 로봇 없이 시작 → 10/8 생성 흐름을 로봇 없이 끝까지(W122) · 기본 설계 CAD · 스캔 촬영 → 10/9(로봇 없음) 스캔 추론기 · 화면 → 10/10~12 생성 설계 조립 · 스캔 복제 실기 → 10/13 저녁 동결 → 10/14~15 리허설 → 10/16 시연.
