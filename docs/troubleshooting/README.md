## 쓰는 법
1. 파일 이름 `TS-번호_짧은제목_v1_<MMDDHH>.md`. 관련 위험 · 할 일 번호(R-xx)가 있으면 제목 뒤에 붙인다. 위 표에 한 줄 추가.
2. 항목: 날짜 · 증상(오류 문구 그대로) · 피해 · 영향 · 원인(추정이면 '추정') · 해결 · 재발 방지 · 상태와 남은 확인.
3. 팀이 같이 알아야 할 에러는 GitHub 이슈(`.github/ISSUE_TEMPLATE/bug_report.md` 양식)로도 연다. 해결하면 이슈 댓글에 해결 방법을 남기고 닫는다.
4. 규칙으로 굳힐 내용은 [설계 문서](../03_설계_SDD_v3_100819.md)나 [팀 협업 규칙](../06_팀협업규칙_v1_100719.md)에 반영하고 여기서 링크한다.
