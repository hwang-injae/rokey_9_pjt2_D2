# CAD 설계도대로 젠가 블록 가구를 쌓는 협동로봇 — 자동 모드 · 협동 모드

사람이 말로 가구를 고르면, 협동로봇이 **CAD 설계도(레시피)대로 젠가 블록을 하나씩 집어 쌓는다.** 혼자 쌓는 **자동 모드**와 사람과 차례를 바꿔 같은 가구를 쌓는 **협동 모드**가 있다. 협동 모드에서는 사람이 설계도의 빈 자리 중 아무 곳에 블록을 놓아도, 로봇이 손목 카메라로 어디까지 쌓였는지 보고 다음 블록을 골라 이어 쌓는다. 모든 이동은 MoveIt2(로봇팔 동작 계획 소프트웨어)로 계획해 쌓인 블록과 사람 팔을 피한다.

> 두산 ROKEY Boot Camp 9기 · 협동-2 · **D2팀**: 박진용 · 한세교 · 민범진 · 한석형 · 황인재(PL) · 2026-10-01 ~ 10-16

| 항목 | 내용 |
|---|---|
| 하드웨어 | Doosan M0609(6축 협동로봇) + OnRobot RG2 그리퍼 + 손목 카메라 Intel RealSense D435i(깊이) + 웹캠(작업대 전체) + 마이크 |
| 소프트웨어 | Ubuntu 24.04 · ROS 2 Jazzy · MoveIt2 · CycloneDDS · Docker · DB(제품 미정) · 웹 화면 |
| 상태 | **1차 구현 중** (1차 완성 10/7 · 챌린지 10/8~13 · 시연 10/16) |
| 차별점 | 사람이 **순서와 상관없이** 블록을 놓아도 로봇이 진행 상태를 읽고 이어 쌓는다 → [선행 프로젝트와 차별점](docs/research/README.md) |

## 주요 기능

- **CAD 설계도 → 블록 하나씩 집기 · 놓기** — 설계도는 한세교가 만든 Advanced 레시피 형식(`cad_recipe/1.0`)이다. 블록마다 자리 · 자세 · 쌓는 순서(sequence) · 받침 · 잡기 후보가 들어 있다. 설계 좌표에 조립 원점(작업영역 가운데를 로봇으로 한 번 찍은 값)을 더해 로봇 좌표를 만든다. 1차 설계는 **lv1_bench(벤치, 블록 11개 = 다리 벽 8 + 좌판 3)**.
- **모든 이동을 MoveIt2로** — 자주 가는 길은 정해 두고, 출발 전에 장면(Planning Scene, 피할 물체를 넣어 두는 가상 공간)에 막히는 것이 있으면 다시 계획한다. 쌓인 블록 · 사람 팔을 장면에 넣고, 쥔 블록은 팔의 일부(붙은 물체)로 보고 같이 피한다. 움직이는 중에 새 경로로 갈아타는 것은 챌린지 ①이다.
- **블록마다 배치 확인** — 블록을 놓을 때마다 손목 카메라(깊이)로 제자리에 놓였는지 본다. 배치 목표 ±2 mm 안이면 그대로, 조금 더 어긋나면 위층에서 보정, 기준을 넘거나 무너지면 멈추고 사람을 부른다.
- **사람과 번갈아 쌓기(협동 모드)** — 사람이 설계도의 빈 자리에 2~3개를 놓고 손을 빼면, 웹캠과 손목 카메라가 **둘 다** 손이 3초 이상 안 보이고 칸이 바뀐 것을 확인한 뒤 로봇 차례가 된다(출발 2초 전 소리 · 화면 알림). 로봇은 sequence에서 아직 안 놓인 첫 블록부터 이어 쌓고, 양쪽이 막혀 손가락이 못 들어가는 칸은 사람에게 부탁한다.
- **말로 고르고, 화면으로 출발** — 웨이크워드 "hello rokey" → 받아 적기(STT) → GPT가 말의 뜻만 분류(설계 선택 · 모드 바꾸기). 로봇 출발은 **화면 버튼 · 키로만** 한다(음성이 틀려도 로봇은 움직이지 않는다).
- **언제나 멈춤** — 펜던트 비상정지 · 터미널 Ctrl+C · 화면 정지 버튼 · 키 · 음성 '멈춰'(보조, PC 안에서 바로 알아듣는 키워드). 로봇 차례에 웹캠이 로봇 작업 영역 안 사람을 보거나 카메라 신호가 1초 끊겨도 멈춘다. 늘 켜 둔 **정지 노드**가 제어기에 '지금 자리에 서기' 궤적을 직접 보내고, 화면 '다시 시작'으로만 잠금이 풀린다.
- **기록** — 기록기 노드 하나가 모든 사건을 실행 번호(run_id)로 남긴다. 1차는 CSV, 그다음 DB(Docker 컨테이너)와 대시보드.

  <sub>노드 지도(파트별 담당) · 연결은 <a href="docs/images/구조2_자동모드흐름_v1_100413.png">자동 모드 흐름</a> · <a href="docs/images/구조3_정지흐름_v1_100413.png">정지 흐름</a> · <a href="docs/images/구조4_협동차례흐름_v1_100413.png">협동 차례 흐름</a> · <a href="docs/images/장면_설명_v1_100413.png">MoveIt2 장면</a></sub>

**PC 2대로 시작한다**(부하를 보고 3대로 늘린다). 모든 노드를 어느 PC에서나 돌게 짠다. 로봇에 붙은 노드(브링업 · MoveIt2 · 정지 · 손목 비전)는 로봇 PC의 호스트에서, DB와 서비스 PC 노드들은 Docker 컨테이너(host 네트워크)에서 돈다. ROS 2 통신은 **CycloneDDS**로 통일하고, 모든 PC · 컨테이너가 같은 `ROS_DOMAIN_ID`(번호 미정)를 쓴다.

| 위치 | 구성 | 실행 |
|---|---|---|
| 로봇 PC (로봇과 유선) | 두산 드라이버 · MoveIt2 `move_group`(브링업) · 집기 · 놓기 + 실행기 · 장면 관리 · 그리퍼 노드 · **정지 노드(고정)** · 손목 블록 인식 · 손목 손 찾기 | 호스트 |
| 서비스 PC | 작업 관리자 · 작업 판단 · 웹캠 사람 감지 · 웹 화면 · 음성 · 기록기 · DB (+ 음성 멈춰) | Docker 컨테이너 |

주요 통신은 아래와 같다. 이름은 모두 `/d2/` 아래에 있고, 요청-결과가 있는 것은 전용 메시지 패키지 `d2_interfaces`, 상태 방송은 JSON 문자열(`std_msgs/String`)이다.

| 통신 | 종류 | 방향 | 내용 |
|---|---|---|---|
| `/d2/hmi/command` | 서비스 | 화면 → 작업 관리자 | 설계 선택 · 모드 · 출발 · 사람 차례 끝 · 이어 하기 (**출발은 화면에서만**) |
| `/d2/hmi/intent` | 토픽(JSON) | 음성 → 작업 관리자 | 말의 뜻(설계 선택 · 모드 바꾸기 · 진행 묻기 · 취소) |
| `/d2/safety/stop_request` | 토픽(JSON) | 화면 · 키 · 음성 멈춰 → 정지 노드 | 정지 요청 |
| `/d2/vision/human_zone` | 토픽(JSON) | 웹캠 → 정지 노드 · 작업 관리자 | 구역별(조립 · 로봇 공급 · 이동 길 · 사람 공급) 사람 있음 · 없음 |
| 서기 궤적 | 액션(`FollowJointTrajectory`) | 정지 노드 → 두산 제어기 | 지금 관절값으로 0.3초 궤적 — 제어기에 직접 |
| `/d2/safety/state` · `/d2/safety/resume` | 토픽(JSON) · 서비스 | 정지 노드 → 모두 · 화면 → 정지 노드 | 멈춤 · 잠금 상태 / 화면 '다시 시작'으로만 잠금 풀기 |
| `/d2/vision/check_progress` | 서비스 | 작업 관리자 → 손목 블록 인식 | 블록마다 있음 · 없음 · 위치 오차 · 윗면 높이 |
| `/d2/task/next_block` | 서비스 | 작업 관리자 → 작업 판단 | 다음 블록 · 공급 칸 · 집는 자세 · 놓는 자세 · 잡기 방법 |
| `/d2/task/progress` | 토픽(JSON) | 작업 판단 → 모두 | 진행표(블록마다 놓였나 · 얼마나 어긋났나) |
| `/d2/motion/pick_place` | 액션 | 작업 관리자 → 집기 · 놓기 | 블록 1개 전체(접근 → 잡기 → 옮기기 → 놓기 → 물러나기) |
| `/d2/gripper/command` | 서비스 | 집기 · 놓기 → 그리퍼 노드 | 폭 · 힘 → 다 움직인 뒤 잡힘 · 폭 |
| `/d2/task/state` · `notify` · `event` | 토픽(JSON) | 작업 관리자 · 모든 노드 → 화면 · 음성 · 기록기 | 지금 상태 · 사람에게 알릴 말 · 기록할 사건 |

좌표 · 그리퍼 값 · 시간 기준은 코드가 아니라 설정 파일 하나(`config/robot.yaml`)에 둔다. 전체 이름 · 칸 · 단위는 [인터페이스 문서](docs/02_인터페이스_IRD_v1_100415.md), 패키지 · 노드 설계는 [설계 문서](docs/03_설계_SDD_v1_100415.md)에 있다.

**자동 모드** ([흐름 그림](docs/images/구조2_자동모드흐름_v1_100413.png))

```
① 요청      "hello rokey" → "벤치 쌓아 줘" → 화면에 설계 표시
② 출발      화면 버튼 · 키 → 시작 점검(그리퍼 · 카메라 · 로봇 상태)
③ 진행 확인  손목 카메라로 놓인 블록 확인 · 웹캠 · 손목으로 사람 없음 확인
④ 다음 블록  레시피 sequence 에서 아직 안 놓인 첫 블록(받침이 있는 것)
⑤ 집기      로봇 공급 영역의 칸에서 레시피 잡기 후보로 10 N 집기 → 그리퍼 폭으로 잡혔는지 확인
⑥ 옮기기    MoveIt2 — 정해진 길, 출발 전 막히면 다시 계획, 움직이는 중 사람이 들어오면 멈춤
⑦ 놓기 · 확인 위치 제어로 놓기 → 블록마다 손목 카메라로 배치 확인 → 11개를 다 놓을 때까지 ③~⑦
```

**협동 모드 — 1차는 번갈아 하기** ([흐름 그림](docs/images/구조4_협동차례흐름_v1_100413.png))

```
① 모드 바꾸기  "같이 하자" 또는 화면 → 쥔 블록을 놓은 뒤 바뀜
② 사람 차례   로봇은 관측 자세에서 멈춰 있음 · 사람은 사람 공급 영역에서 블록을 가져와 빈 자리에 2~3개
③ 차례 끝     웹캠 · 손목 모두 손 3초 이상 안 보임 + 칸 변화 → 출발 2초 전 알림 → 로봇 차례 (화면 버튼은 예비)
④ 로봇 차례   진행 확인 → 다음 블록 → 출발 전 사람 팔을 장면에 넣고 계획 → 집기 · 옮기기 · 놓기
⑤ 다시 사람 차례 관측 자세로 돌아가 기다림 → ②부터 반복
```

사람은 아무 순서로 놓아도 되지만 설계도에 있는 자리여야 한다. 설계에 없는 자리이거나 많이 어긋나면 로봇이 멈추고 다시 놓아 달라고 알린다. 단계별 상태표는 [설계 문서](docs/03_설계_SDD_v1_100415.md)에 있다.

### 예외 처리

판단은 한 곳에서 한다 — 멈출지는 **정지 노드**, 차례를 넘길지는 **작업 관리자**, 진행표는 **작업 판단**, MoveIt2 장면은 **장면 관리**가 정한다. 다시 시작할 때는 항상 진행 확인부터 하고, 그리퍼 폭으로 쥔 블록이 있는지도 본다.

| 상황 (실패 이유 코드) | 로봇 | 사람 |
|---|---|---|
| 경로 계획 실패 (`PLAN_FAILED`) | 다시 계획 1번 → 그래도 안 되면 사람 호출 | 원인을 치우고 화면에서 이어 하기 |
| 잡기 실패 (`GRASP_FAILED`) · 공급 칸이 빔 (`SLOT_EMPTY`) | 1번 더 잡기 → 다음 공급 칸 → 사람 호출 | 공급 칸 채우기 |
| 블록이 많이 어긋남 (`OFFSET_OVER`) | 멈추고 사람 호출 (1차는 보정 · 알림만, 다시 놓기는 챌린지) | 블록을 바로 놓기 |
| 양쪽이 막힌 칸 (`BLOCKED_BOTH_SIDES`) | 그 블록은 건너뛰고 사람에게 부탁(알림) | 그 블록을 손으로 놓기 |
| 로봇 차례에 사람이 들어옴 (`HUMAN_IN_ZONE`) · 비전 신호 1초 끊김 (`VISION_LOST`) · 정지 입력 | 정지 노드가 서기 궤적을 보내고 잠금(`STOPPED`) | 확인 뒤 화면 '다시 시작' → 진행 확인부터 |
| 시간 초과 (`TIMEOUT`) | 사람 호출 | — |

펜던트 비상정지와 두산 충돌 감지는 이 흐름과 상관없이 늘 작동한다. 서기 궤적이 2초 안에 듣지 않으면 두산 `move_stop`, 그래도 안 서면 펜던트로 세운다([정지 흐름 그림](docs/images/구조3_정지흐름_v1_100413.png)). 움직이는 중 Ctrl+C로 바로 서는 것은 10/4 실기에서 확인했다([TS-01](docs/troubleshooting/TS-01_정지가_안_들음_R-01_v1_100414.md)).

## 실행 방법

**(코드 작성 전 — 패키지가 생기면 채움)**

저장소 받기:

```bash
git clone https://github.com/hwang-injae/rokey_9_pjt2_D2.git
cd rokey_9_pjt2_D2
```

패키지가 생기면 여기에 ROS 2 · 두산 드라이버 설치, `colcon build`, 로봇 없이(가짜 노드 `mock_*`) 실행, 가상 로봇(에뮬레이터), 실제 로봇(PC 2대 · CycloneDDS · Docker) 순서로 그대로 따라 할 명령을 적는다.

> 로봇을 움직이는 코드는 반드시 정지 처리(서기 궤적)를 넣는다. 새 코드 첫 실행은 저속으로, 펜던트를 든 짝과 함께 한다. 급할 때는 Ctrl+C가 아니라 **펜던트 비상정지**.
